\section{Introducción}

\begin{frame}[c]{Introducción}

En la actualidad, la educación enfrenta el reto de adaptarse a
entornos digitales cada vez más dinámicos, donde el uso de
\textbf{Tecnologías de la Información y la Comunicación} (TIC) es
fundamental para mejorar los procesos de \emph{enseñanza-aprendizaje}.

\vspace{1em}
La evolución tecnológica ha desplazado los métodos tradicionales
(como la oralidad y los textos impresos) hacia la virtualidad.
\end{frame}

\section{Trabajos relacionados}

\begin{frame}[c]{Trabajos relacionados}

Plataformas como \textbf{Google Classroom}, \textbf{Moodle} y
los \emph{cursos en línea masivos y abiertos} o \textbf{MOOC} (acrónimo
en inglés de \emph{massive open online courses}) han permitido
ampliar el acceso a recursos educativos; sin embargo, aún existen
desafíos importantes en la personalización del aprendizaje y la
evaluación continua.

\begin{frame}[c]{Áreas de mejora}
  \begin{itemize}
    \item Los sistemas actuales \textbf{no} generan preguntas
        a\textbf{utomáticas} o \textbf{aleatorias}.
    \pausa
    \item Las preguntas \textbf{casi siempre} son las mismas para
        todos los estudiantes.
    \begin{itemize}
      \item Se pueden copiar las respuesta entre los alumnos
      \item Se pueden copiar las preguntas y guardarlas para
          el siguiente ciclo.
    \end{itemize}
    \pausa
    \item Se necesita tener \textbf{acceso a Internet} para todos
        los alumnos.
    \begin{itemize}
      \item Uso de PC o en rara vez en ceular.
    \end{itemize}
  \end{itemize}
\end{frame}

\section{Justificación}

\begin{frame}[c]{Justificación}
  \begin{itemize}
    \item Crear un sistema que genere preguntas \textbf{automáticas} o
        \textbf{aleatorias} de matemáticas.
    \pausa
    \item \textbf{Evitar la copia} entre alumnos al ser preguntas
        diferentes.
    \pausa
    \item Acceso al sistema \textbf{sin necesidad} de Internet.
  \end{itemize}
\end{frame}

\section{Objetivos}

\begin{frame}[c]{Objetivo general}
  \begin{itemize}
    \item Desarrollar un asistente virtual que permita la generación
      y evaluación automática de ejercicios matemáticos para apoyar
      la adquisición de competencias técnicas en estudiantes de
      educación media superior.
  \end{itemize}
\end{frame}

\begin{frame}[c]{Objetivos específicos}
  \begin{enumerate}
    \item \label{itm:objetivo1} Desarrollar un sistema que realice exámenes
      y ejercicios de manera autónoma y aleatoria.
    \pausa
    \item \label{itm:objetivo2} Crear una herramienta que permita a los
      profesores crear, modificar y administrar las pruebas y ejercicios de
      aprendizaje.
    \pausa
    \item \label{itm:objetivo3} Crear una herramienta que permita a los
      alumnos realizar sus exámenes y ejercicios.
    \pausa
    \item \label{itm:objetivo4} Crear un ambiente seguro para la realización
      de los exámenes.
    \pausa
    \item \label{itm:objetivo5} Crear un sistema que no requiera la conexión
      a Internet para que se conecten los alumnos.
  \end{enumerate}
\end{frame}

\section{Propuesta}

\begin{frame}[c]{Propuesta}
  \begin{enumerate}
    \item Creación de una aplicación web que no necesite conexión a
      Internet.
    \pausa
    \item Uso de Hardware de bajo consumo como la Raspberry Pi o la NUC para
      actuar como servidor local.
      \begin{itemize}
        \item El tamaño pequeño ayuda a su transportación y manejo en el
          salón.
        \item Usar este mismo equipo como punto de acceso inalámbrico
          (un hostpot), para acceder al sistema.
      \end{itemize}
  \end{enumerate}
\end{frame}

\section{Conclusiones}

\begin{frame}[c]{Conclusiones}
Este sistema nos da las siguientes ventajas:
  \begin{enumerate}
    \item Los alumnos \textbf{no están conectados a Internet}, para usar la
      IA o google para hacer trampa.
  \pausa
  \item \textbf{No se necesita Internet} para usar el sistema
  \pausa
  \item Los \textbf{ejercicios} y \textbf{exámenes} se generan y califican
    \textbf{automáticamente}
  \pausa
  \item Las preguntas son \textbf{diferentes} para cada alumno
  \pausa
  \item Los alumnos pueden usar una PC o su propio celular
  \end{enumerate}
\end{frame}
